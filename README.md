# Bingo 25 — Vercel-ready
A 5×5 Bingo game using numbers 1–25, styled to match the supplied screenshot.

Features:
- 25 unique numbers on a 5×5 board, randomized with Auto fill
- Manual number editing (1–25)
- Tap to mark/unmark numbers
- Easy / Medium / Hard modes with different point values
- Verify any completed row, column, or diagonal
- Score, turn counter, leaderboard-style current-session panel
- Responsive mobile layout and animated winning lines

Run locally:
```bash
npm install
npm run dev
```
Deploy: import this folder's GitHub repository into Vercel. Framework Vite, build `npm run build`, output `dist`. No backend or environment variables required.
